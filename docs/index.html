One question, two tool calls

The agent picks the tools, calls them, and answers from what Steam returns. This exchange used two keyless tools. The numbers are what Steam reported on 22 November 2026.

See every tool and what it needs

  1. You ask

    How many people are playing Team Fortress 2 right now, and how is it reviewed?

  2. The agent calls
    steam_getPlayerCount {"appid":440}
steam_getAppReviewSummary {"appid":440}
  3. Steam returns
    {"appid":440,"player_count":102022}
{"appid":440,"review_score_desc":"Very Positive",
 "total_reviews":1258222,"positive_percentage":91}
  4. The agent answers

    102,022 people are in TF2 right now. Reviews are Very Positive: 91% of 1,258,222.

Setup

Requires Node.js 22 or later. Nothing to clone or build: your client starts the server with npx.

Cursor

{
  "mcpServers": {
    "steam": {
      "command": "npx",
      "args": ["-y", "@tmhs/steam-mcp"],
      "env": { "STEAM_API_KEY": "your_key_here" }
    }
  }
}

Save as .cursor/mcp.json in a project, or ~/.cursor/mcp.json for all projects. Pair it with the Steam Developer Tools plugin for skills that use these tools.

Claude Code

claude mcp add steam -e STEAM_API_KEY=your_key_here -- npx -y @tmhs/steam-mcp

Run once in a terminal. Leave out -e STEAM_API_KEY=... to start with the keyless tools only.

HTTP

npx -y @tmhs/steam-mcp --transport http --port 3000
# serves http://127.0.0.1:3000/mcp, GET /healthz returns {"ok":true}

Stateless Streamable HTTP for hosted or team setups. Binds to 127.0.0.1 unless you pass --host, refuses Host headers outside STEAM_MCP_ALLOWED_HOSTS, never takes a key from clients, and keeps write tools off unless STEAM_MCP_HTTP_ALLOW_WRITES=1. A Dockerfile is in the repo.

Which key do you need?

  • None for store lookups, search, player counts, prices, reviews, news, Deck status, and art checks. Leave STEAM_API_KEY out.
  • A free Steam Web API key from steamcommunity.com/dev/apikey for profiles, libraries, player achievements, Workshop search, and bans.
  • A publisher key from Steamworks, with the server's IP allowlisted, for leaderboards, betas, builds, ownership, inventory, and every write tool.
  • A Financial API Group key for sales reports. Set it as STEAM_FINANCIAL_API_KEY.

The server reads keys from its own environment only. It does not load a .env file.

Write safety

Write tools do nothing until you confirm. The 5 tools that change live Steam data are off by default. When you turn them on, every call is a dry run that returns a plan and sends nothing. A live call needs both dry_run: false and confirm: true. Without confirm it is refused with [CONFIRM_REQUIRED].

Write tools take a literal Steam64 ID, never a vanity name, so a lookup mistake cannot redirect a change. Reviews, Workshop text, and news come back labeled as third-party content, for the agent to summarize rather than follow. See SECURITY.md to report a vulnerability.

Toolsets

Load only the toolsets you use. Fewer tools means less for the agent to read on every turn. Set STEAM_MCP_TOOLSETS to a comma-separated list. The steam://server-info resource tells the agent which toolsets are off, so it can explain a missing tool.

ToolsetToolsCoversDefault
store12Store pages, search, player counts, prices, reviews, news, Deck status, featured lists.On
community8Profiles, libraries, player achievements and stats, Workshop, bans.On
publisher10Leaderboards, achievement schemas, global stats, betas, builds, ownership, inventory, sales.On
assets2Check capsule, hero, logo, and icon art against Valve's sizes before you upload.On
sdk2C++, C#, and GDScript for lobbies and Workshop uploads, which need the Steamworks SDK.On
mutations5Set or clear achievements, upload scores, grant items, edit Workshop metadata.Off
 
"env": { "STEAM_API_KEY": "your_key_here", "STEAM_MCP_TOOLSETS": "store,publisher,mutations" }

Prompts

Ready-made workflows that most clients show as slash commands. Each one tells the agent which tools to chain and what to report.

  • competitor-snapshotCompare several Steam games: price, reviews, live players, and recent news.
  • achievement-healthFind achievements that look unobtainable, trivial, or badly described.
  • review-digestSummarize recent Steam reviews into themes, with quotes and counts.
  • regional-price-auditCheck an app's regional prices for outliers before a sale or price change.
  • launch-readinessPass/fail checklist for a store page: local art folder plus the live store listing.
  • workshop-healthSee what is trending, what is top-rated, and whether top items are going stale.

Resources

Reference data the agent can read instead of guessing.

  • steam://specs/store-assetsPixel sizes, formats, and alpha rules for every slot steam_validateStoreAsset checks.
  • steam://enums/eresultWhat common EResult numbers in Steam errors and X-eresult headers mean.
  • steam://enums/ugc-query-typesteam_queryWorkshop sort names and the EPublishedFileQueryType values they map to.
  • steam://enums/review-filterssteam_getReviews filter, review_type, and purchase_type names and their GetAppReviews enum values.
  • steam://app/{appid}/summaryCompact store summary for an app (the same as steam_getAppDetails' default output).

Configuration

Every setting is an environment variable in your client's env block. These are the common ones. The README and .env.example list every setting, including HTTP host and port.

VariableDefaultWhat it does
STEAM_API_KEYunsetSteam Web API key. Leaderboard, partner, and write tools need a publisher key with the server's IP allowlisted.
STEAM_FINANCIAL_API_KEYSTEAM_API_KEYFinancial API Group key for the two sales tools.
STEAM_MCP_TOOLSETSall but mutationsComma-separated toolsets to load, or all.
STEAM_MCP_READ_ONLYunset1 removes mutations even if it is listed.
STEAM_MCP_CACHE_TTLper endpoint0 turns off the in-memory cache. Any other number of seconds replaces every TTL.
STEAM_MCP_DEBUGunset1 logs each Steam request (host, path, query keys, status, latency) to stderr. Never logs values.
STEAM_MCP_TRANSPORTstdiostdio or http, same as --transport.

Steam Developer Tools

This server is the live-data half of Steam Developer Tools, a Cursor plugin with 30 skills and 9 rules for Steamworks development. The skills call these tools to check real store pages, stats, and leaderboards while you build.
