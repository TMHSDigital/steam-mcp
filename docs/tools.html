Tool reference

All 39 tools, generated from the server's own registrations: the description your agent reads, the inputs it can pass, and the key the tool needs. Tool names in the server are prefixed steam_.

  • No key
  • Local, no network
  • Steam Web API key
  • Publisher key
  • Financial API key

store 12 tools, on by default

Store pages, search, player counts, prices, reviews, news, Deck status, featured lists.

Get App Details

steam_getAppDetailsNo keyRead only

Get Steam store data for an app. Returns a compact summary by default (price, release date, genres, platforms, metacritic, short description). Pass detail: "full" or a fields list for descriptions, requirements, screenshots, DLC, and the rest. No API key required.

Inputs
appid requiredSteam application ID (e.g. 440 for Team Fortress 2)
ccTwo-letter country code for pricing (e.g. US, GB, DE)
lLanguage code for descriptions (e.g. english, german)
detailsummary (default): name, type, price, release date, genres, categories, platforms, metacritic, recommendations, and the short description, about 2 KB. full: every store field, about 30 KB.
fieldsReturn only these raw store fields (e.g. ["pc_requirements", "dlc", "screenshots"]). Overrides detail.
include_htmlKeep store HTML in description and requirements fields (default: false, which strips tags and truncates long text to 2000 chars).

Search Apps

steam_searchAppsNo keyRead only

Search the Steam store for games and apps by name or keyword. Returns app IDs, names, icons, and price info. No API key required.

Inputs
query requiredSearch query for games or apps (e.g. 'Hades', 'Counter-Strike')
ccTwo-letter country code for pricing (e.g. US, GB)
lLanguage code (e.g. english, german). Defaults to english.

Get Price Overview

steam_getPriceOverviewNo keyRead only

Batch price check for multiple Steam apps in a specific region. Returns formatted price data including base price, discount, and final price. No API key required.

Inputs

ccTwo-letter country code for pricing (e.g. US, GB, DE). Defaults to server region.

Get Regional Pricing

Get pricing for a Steam app across multiple regions/countries. Returns price, currency, and discount info for each region. No API key required.

Inputs

Get Reviews

steam_getReviewsNo keyRead only

Fetch user reviews for a Steam app with filters for language, sentiment, purchase type, and pagination. Uses IUserReviewsService/GetAppReviews. No API key required.

Inputs
appid requiredSteam application ID
filterSort order: all (most helpful), recent (newest), updated (recently updated), or funny (default: all). Use recent or updated when paging through every review with cursor.
languageSteam API language code, or a comma-separated list (e.g. english, german, all). Default: english.
review_typeFilter by review sentiment (default: all)
purchase_typeFilter by purchase type (default: steam)
num_per_pageNumber of reviews to return (default: 20, max: 100)
cursorPagination cursor from a previous response

Get all-time review summary statistics for a Steam app across all languages and purchase types: total positive/negative counts, review score, and score description. No individual reviews returned. No API key required.

Inputs

Get the Steam store's current top sellers, new releases, specials, and coming-soon lists for a region. Prices are in the currency's smallest unit (cents). No API key required.

Get a player's Steam profile including display name, avatar, online status, and profile visibility. Requires STEAM_API_KEY.

Inputs

Get Owned Games

steam_getOwnedGamesSteam Web API keyRead only

Get a player's game library with playtime data. Returns the library size and total playtime, plus the top 50 games by playtime by default (change with sort and limit, or filter with appids). Requires STEAM_API_KEY.

Inputs
steamid requiredThe player: a 17-digit Steam64 ID, a profile URL (steamcommunity.com/profiles/... or /id/...), a vanity name, or a SteamID2/SteamID3 (STEAM_0:1:123, [U:1:246])
include_played_free_gamesInclude free-to-play games in results (default: true)
include_appinfoInclude game name and icon info (default: true)
sortOrder games by total playtime (default), playtime in the last two weeks, or name
limitMaximum games to return after sorting (default: 50). game_count always reports the full library.
appidsOnly return these apps, e.g. to check whether the player owns them

Query Workshop

steam_queryWorkshopSteam Web API keyRead only

Search and browse Steam Workshop items for a given app. Filter by text, tags, and sort order. Requires STEAM_API_KEY.

Inputs
appid requiredApp ID to search workshop items for (e.g. 440 for TF2)
search_textText to search for in item titles and descriptions
cursorPagination cursor. Use '*' for the first request, then pass the cursor from previous results.
numperpageNumber of results per page (1-100, default 10)
sortSort order: vote (top rated), date (newest), trend (most popular over `days`), text_search (relevance to search_text), subscriptions (most subscribed), playtime (most total playtime), updated (recently updated). Default: text_search when search_text is set, otherwise date.
daysTrend window in days (1-7). Only used with sort: trend.
requiredtagsTags to filter on, e.g. ["Map", "Weapon"]. See match_all_tags.
match_all_tagsIf true (default), items must have every tag in requiredtags. If false, any one tag matches.
excludedtagsTags that items must NOT have
return_tagsInclude each item's tags in the results (default: true)
return_previewsInclude preview image and video details (default: false)

publisher 10 tools, on by default

Leaderboards, achievement schemas, global stats, betas, builds, ownership, inventory, sales.

Get Leaderboards For Game

steam_getLeaderboardsForGamePublisher keyRead only

List all leaderboards for a Steam app with their numeric IDs, names, and sort methods. steam_getLeaderboardEntries and steam_uploadLeaderboardScore accept either the leaderboardid or the leaderboard_name; use this tool to see which leaderboards exist. Requires a Steam Publisher API key (STEAM_API_KEY) for an app you own, with the server IP allowlisted. A regular user key gets HTTP 403.

Inputs
appid requiredSteam application ID to list leaderboards for

Get Leaderboard Entries

steam_getLeaderboardEntriesPublisher keyRead only

Get leaderboard scores and rankings for a Steam app. Pass the numeric leaderboardid or the leaderboard_name (resolved through GetLeaderboardsForGame; the output then includes resolved_from). Uses the partner API (partner.steam-api.com) which requires a publisher API key with server IP allowlisted in Steamworks. Supports global, around-user, and friends-only views.

Inputs
appid requiredSteam application ID
leaderboardidNumeric leaderboard ID (Steamworks dashboard > Leaderboards, or steam_getLeaderboardsForGame). Pass this or leaderboard_name.
leaderboard_nameLeaderboard name (API name or display name) as listed by steam_getLeaderboardsForGame. Use instead of leaderboardid; it is resolved to the numeric ID.
rangestartStart of the range. Global (0) and Friends (2): a rank index, 0 or more (default: 0). Around user (1): an offset from the user, negative for players above them (default: -10).
rangeendEnd of the range, inclusive. Global and Friends: a rank index (default: 100). Around user: an offset from the user (default: 10). At most 500 entries per call; page with rangestart/rangeend.
datarequestRequest type: 0 = Global, 1 = Around user, 2 = Friends (default: 0)
steamidSteam ID required for AroundUser (1) and Friends (2) requests
include_namesAdd each player's persona name (personaname) to the entries, looked up with ISteamUser/GetPlayerSummaries in batches of 100 (default: false)

Get Schema For Game

steam_getSchemaForGameSteam Web API keyRead only

Get the achievement and stat schema for a Steam app: achievement internal names, display names, descriptions, and hidden flags, plus stat definitions. Useful for mapping internal ACH_ names to human-readable names. Returns up to 100 achievements without icon URLs by default (see limit, include_icons, include_stats). Requires STEAM_API_KEY.

Inputs
appid requiredSteam application ID to get the achievement/stat schema for
limitMaximum achievements to return (default: 100). achievement_count always reports the total.
include_statsInclude stat definitions (default: true)
include_iconsInclude achievement icon URLs (default: false)

Get Global Stats For Game

steam_getGlobalStatsForGameNo keyRead only

Get all-player totals for a game's aggregated stats (for example total kills or distance traveled), optionally with daily history. Only stats flagged as aggregated in Steamworks return data. No API key required when stat_names is given.

Inputs
appid requiredSteam application ID
stat_namesStat API names to total. Only stats flagged as aggregated in Steamworks work. If omitted and STEAM_API_KEY is set, the first 50 stats from the app's schema are requested, and the output says how many were left out.
history_daysAlso return a daily total for each of the last N days (1-60)

Get Sales Summary

steam_getSalesSummaryFinancial API keyRead only

Summarize your Steam sales for a date range (up to 31 days): units sold, returned, and activated, and gross and net revenue in USD, grouped by country, day, app, package, or platform, optionally compared with the previous period of the same length. Reads IPartnerFinancialsService with a Financial API Group key (STEAM_FINANCIAL_API_KEY, or STEAM_API_KEY), server IP allowlisted.

Inputs
start_date requiredDate in YYYY-MM-DD, Pacific Time (Steam's financial day)
end_dateLast date, inclusive (default: start_date). At most 31 days after start_date.
appidOnly count sales of this app (matches appid or primary_appid)
group_byHow to group the totals (default: country)
topReturn the top N groups by net revenue (default: 25)
formatjson (default) or csv for spreadsheets
compare_previousAlso total the same-length period ending the day before start_date, and add previous_*, delta_*, and delta_pct to each group and to totals (default: false). Doubles the number of requests. With group_by day, each day is compared with the day the same distance into the previous period.

Get Changed Sales Dates

steam_getChangedSalesDatesFinancial API keyRead only

List the dates whose Steam sales data changed since a highwatermark, for incremental syncing. Pass the returned result_highwatermark next time. Dates are Pacific Time. Needs a Financial API Group key (STEAM_FINANCIAL_API_KEY, or STEAM_API_KEY).

Inputs
highwatermarkresult_highwatermark from your last call (default: 0, which returns every date with sales)

assets 2 tools, on by default

Check capsule, hero, logo, and icon art against Valve's sizes before you upload.

Validate Store Asset

steam_validateStoreAssetLocal, no networkReads local files

Validate a local store, library, achievement, community, or event image against Valve's pixel sizes, format rules, and library-hero heuristics. Pass a directory with slot achievementIcon to check a whole achievement icon set, including missing achieved/unachieved pairs. No API key required.

Inputs
path requiredLocal path to a PNG or JPEG. For slot achievementIcon, may also be a directory: every image is checked and each <name>_achieved needs a <name>_unachieved.
slot requiredAsset slot: store capsules (headerCapsule, smallCapsule, mainCapsule, verticalCapsule), library (libraryCapsule, libraryHero, libraryLogo, libraryHeader), screenshot, pageBackground, achievementIcon (256x256 JPG), communityIcon (184x184 JPG), eventCover (800x450), eventHeader (1920x622)

Validate Store Asset Folder

steam_validateStoreAssetDirLocal, no networkReads local files

Audit a folder of store art before launch. Infers each image's slot from its file name (hero, logo, header, small, main, vertical, library, screenshot, ...) or its exact size, validates it, and lists missing required slots (headerCapsule, smallCapsule, mainCapsule, verticalCapsule, libraryCapsule, libraryHero, libraryLogo) and whether there are at least 5 valid screenshots. No API key required.

Inputs
dir requiredLocal folder containing the store and library images
slotsOptional file name -> slot, for files whose name and size do not identify them, e.g. { "key_art_final.png": "libraryHero" }. Wins over inference (reported as inferred_by "explicit"); names not in the folder come back as warnings.

steam_uploadWorkshopItemLocal, no networkCode guide, no network

Get code examples and documentation for uploading new Steam Workshop items. Workshop uploads require the Steamworks SDK (ISteamUGC) running in a client or dedicated tool — there is no HTTP upload endpoint. This tool returns ready-to-use code for C++, C#, and GDScript.

Inputs

title requiredTitle for the Workshop item
descriptionDescription for the Workshop item
content_pathLocal folder path containing the item content
preview_pathLocal path to a preview image (JPG/PNG, <1MB)
tagsTags for discoverability
visibilityItem visibility (default: public)

mutations 5 tools, off by default

Set or clear achievements, upload scores, grant items, edit Workshop metadata.

Update Workshop Item

steam_updateWorkshopItemPublisher keyLive write, confirm-gated

MUTATES LIVE WORKSHOP ITEM METADATA. Default dry_run=true; requires confirm=true to send. Update metadata for an existing Steam Workshop item (title, description, visibility, tags) via the partner API. Does not change the store page listing. Requires a publisher API key with server IP allowlisted. File content updates require the SDK.

Inputs
publishedfileid requiredWorkshop item's published file ID
appid requiredSteam application ID
titleNew title for the item
file_descriptionNew description for the item
visibilityVisibility: 0=Public, 1=FriendsOnly, 2=Private, 3=Unlisted
tagsReplace the item's tags with this list
dry_runIf true (default), return the planned request without contacting Steam
confirmRequired true when dry_run is false. Refuses otherwise.

Set Achievement

steam_setAchievementPublisher keyLive write, confirm-gated

MUTATES LIVE ACHIEVEMENT STATE. Default dry_run=true; requires confirm=true to send. Set (unlock) one achievement, or several at once with achievements, for a player via the partner API. The dry run lists every change. Intended for dev/test use. Requires a publisher API key with server IP allowlisted in Steamworks partner settings.

Inputs
steamid required64-bit Steam ID of the player
appid requiredSteam application ID
achievementAchievement API name (e.g. ACH_BEAT_LEVEL_1). Must match a name configured in Steamworks. Pass this or achievements.
achievementsSeveral achievement API names changed in one dry run and one confirmed call (1-100). Pass this or achievement.
dry_runIf true (default), return the planned request without contacting Steam
confirmRequired true when dry_run is false. Refuses otherwise.

Upload Leaderboard Score

steam_uploadLeaderboardScorePublisher keyLive write, confirm-gated

MUTATES LIVE LEADERBOARD ENTRY. Default dry_run=true; requires confirm=true to send. Upload a score to a Steam leaderboard via the partner API. A dry run accepts leaderboard_name and shows the resolved leaderboardid; the live call takes only the numeric leaderboardid, so the board you confirmed is the board that is written. Requires a publisher API key with server IP allowlisted in Steamworks partner settings.

Inputs
appid requiredSteam application ID
leaderboardidNumeric leaderboard ID. Required for the live call (dry_run: false).
leaderboard_nameLeaderboard name, dry run only: it is resolved to the numeric ID and shown in the plan. Pass that leaderboardid to the live call.
steamid required64-bit Steam ID of the player
score requiredScore to upload (interpretation depends on leaderboard sort method)
scoremethodKeepBest only updates if better than existing; ForceUpdate always overwrites (default: KeepBest)
dry_runIf true (default), return the planned request without contacting Steam
confirmRequired true when dry_run is false. Refuses otherwise.

Grant Inventory Item

steam_grantInventoryItemPublisher keyLive write, confirm-gated

MUTATES LIVE INVENTORY. Default dry_run=true; requires confirm=true to send. Grant an inventory item to a player via the partner API. Intended for dev/test or server-side rewards. Requires a publisher API key with server IP allowlisted in Steamworks partner settings.

Inputs
appid requiredSteam application ID
steamid required64-bit Steam ID of the player to grant the item to
itemdefid requiredItem definition ID from your Steamworks item schema
quantityNumber of copies to grant (default: 1, max: 100). Sent as repeated itemdefid[n] parameters.
notifyWhether to notify the player of the grant (default: true)
itempropsjsonOptional JSON string of dynamic item properties to set on the granted items
requestidIdempotency key. Steam executes a given requestid at most once. A dry run generates one; the live call (dry_run: false) requires it, so pass the dry run's value and a retry cannot double-grant.
dry_runIf true (default), return the planned request without contacting Steam
confirmRequired true when dry_run is false. Refuses otherwise.
